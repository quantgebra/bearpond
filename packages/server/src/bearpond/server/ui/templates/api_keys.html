Using a key

A key acts as the user it was made for, with the groups that an administrator gave that user. Give it to the command line in BEARPOND_TOKEN or --token, or send it in the Authorization header. Revoke it here at once if it leaks.

export BEARPOND_TOKEN=bp_…
bearpond clone {{ page.base_url }}/REPO

curl -H "Authorization: Bearer bp_…" {{ page.base_url }}/repos
